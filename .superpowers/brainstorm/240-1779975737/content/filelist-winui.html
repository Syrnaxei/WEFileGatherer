WinUI3 风格要点

  • 卡片式行块 — 每行独立卡片（rounded 8px + 1px border），行间距 8px，替代紧凑 grid 紧密排列
  • 文件信息聚合 — 文件名(14px 500) + 元数据行(大小高亮accent · 码率 · 时长)，移除冗余路径行
  • Tag + 目标路径融合 — Tag 名称 + 目标路径缩写在同一 chip 内显示，减少列宽碎片
  • 状态徽章 — 待处理/处理中/完成/失败 以文字标签呈现，行卡片背景跟随状态变化
  • 删除按钮 — 使用 WinUI ActionButton + DeleteIcon，hover 时变 error 色
  • Flex 布局 — 替代 Grid 布局，列宽自然适配内容，减少硬编码宽度
  • 悬停效果 — 行卡片 hover 时 border 变亮，背景微亮

⚠️ 需要确认

当前设计中 Tag 和目标路径合并为一个 chip 展示。但如果用户需要经常在文件行中直接输入/选择 tag（当前是 input 下拉），这个合并 chip 的交互方式需要调整。你倾向于哪种？

A

保持 Tag Input 交互不变

Tag 列保持现有的 input 下拉选择器，仅样式 WinUI3 化。目标路径在 Tag 下方以小字 mono 展示。牺牲一点视觉简洁度，保证操作效率。

B

Chip 点击弹出选择

Tag 显示为 chip（含目标路径缩写），点击 chip 弹出下拉选择器。未设置 tag 时显示 "+ 选择 tag" 占位 chip。视觉更干净。
