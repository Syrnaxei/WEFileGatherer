设计要点

  • Toolbar 背景 使用 --settings-tile-bg（#323232），与设置页卡片背景一致
  • StatsBar 背景 使用 --bg-surface-1（#202020），略深于 Toolbar 形成层次
  • 源目录路径 以 accent 色 + mono 字体展示，左侧带 FolderIcon
  • 按钮 使用项目全局 .btn 类（btn-primary / btn-success / btn-danger）
  • 统计数字 使用 mono 字体，各指标用对应语义色（accent/info/success/error/warning）
  • 文件列表 保持现有 FileList 组件不变，仅外层包装样式对齐
  • 垂直节奏：PageHeader(68px) + Toolbar(48px) + StatsBar(44px) + 表头(32px) = 192px 头部总高度
