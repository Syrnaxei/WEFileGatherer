完成/失败状态 — 提示方式备选

替换缩略图上的对勾/叉号角标，以下是 3 种备选方案

A

左侧色条 + 文字状态

卡片左侧 3px 色条（绿色=完成，红色=失败）+ 右侧状态文字。干净简洁，类似 VS Code 文件标签的修改指示。

B

状态圆点 + 文字

缩略图左下角放一个小圆点（绿/红），右侧状态列也显示对应文字。圆点小巧不突兀。

C

仅状态文字着色

完全去掉缩略图上的标记，仅在右侧状态列以带颜色的文字标签展示（绿色"完成"/红色"失败"），配合卡片背景微调。极简风格。
