# 替换应用图标

本文档说明如何替换 Electron 应用的图标。

## 准备工作

1. **准备源文件**：一张 PNG 格式的图标，建议尺寸 **1024×1024** 或更大
2. **背景要求**：建议使用透明背景（或与应用风格匹配的背景）
3. **存放位置**：`assets/icon.png`

## 替换步骤

### 1. 替换源文件

将新图标覆盖到项目根目录：

```bash
# 直接替换文件即可
assets/icon.png
```

### 2. 重新生成平台图标

运行以下命令自动生成各平台所需的图标格式：

```bash
npm run build:icon
```

此命令会：
- 生成 `build/icons/icon.ico`（Windows）
- 生成 `build/icons/icon.icns`（macOS）
- 生成 `build/icons/` 下的多尺寸 PNG（Linux）

### 3. 重新编译打包

```bash
# 完整打包命令
npm run electron:build
```

打包完成后，新图标会出现在：
- 窗口标题栏图标
- 任务栏/Dock 图标
- 安装包图标
- 开始菜单/应用列表图标

## 常见问题

### 开发模式下看不到图标？

开发模式（`npm run electron:dev`）下 Electron 可能显示默认图标，这是正常的。**只有在打包后**才会显示自定义图标。

### 图标显示模糊？

- 确保源文件尺寸至少 **512×512**，推荐 **1024×1024**
- 检查源文件是否为 PNG 格式
- 重新运行 `npm run build:icon` 生成更高质量的图标

### 只想改某个平台的图标？

各平台图标文件位置：
- **Windows**: `build/icons/icon.ico`
- **macOS**: `build/icons/icon.icns`
- **Linux**: `build/icons/512x512.png`（或任意尺寸 PNG）

可以直接用工具生成对应格式的图标放到上述位置，无需重新运行 `npm run build:icon`。

## 技术细节

- `electron-icon-builder` 工具会自动从 `assets/icon.png` 生成所有平台格式
- `package.json` 的 `build.icon` 配置指向 `build/icons/icon.png`
- `src/electron/main.ts` 中设置了窗口图标路径
- `assets/` 目录已配置为 `extraResources`，打包后可通过 `process.resourcesPath` 访问
