# 按钮设计标准

> 适用文件: `web/src/App.tsx`、`web/src/components/*.tsx`

---

## 一、设计原则

- 所有按钮圆角统一为 `4px`（侧边栏导航按钮为 `8px`，开关为 `12px`）
- 聚焦态使用 `outline: 2px solid #3b82f6`（全局定义于 `index.css`）
- 禁用态降低透明度至 `0.5 ~ 0.6`，光标改为 `not-allowed`
- 过渡动画统一使用 `transition: background 0.15s, color 0.15s`

---

## 二、按钮分类

### 1. 主操作按钮 (Primary)

用于页面主要操作：加载、启动、创建。

```css
padding: 6px 14px;
border-radius: 4px;
border: none;
color: white;
font-size: 13px;
cursor: pointer;
white-space: nowrap;
```

| 场景 | 背景色 | 禁用背景色 |
|------|--------|-----------|
| 加载 (工作台) | `#4f46e5` | `#6b7280` |
| 启动 (工作台) | `#10b981` | `#6b7280` |
| 停止 | `#ef4444` | `#6b7280` |
| 加载 (搜刮) | `#4f46e5` | `#6b7280` |
| 启动 (搜刮) | `#10b981` | `#6b7280` |
| 创建 (Tag管理) | `#4f46e5` | — |
| 通用 | `#4b5563` | — |

**代码位置**: `App.tsx` → `btnStyle`, `ScrapePage.tsx` → `btnStyle`, `SettingsPage.tsx` → `smallBtnStyle`

align-items: center;

| 状态 | 图标色 | 背景色 (暗色) | 背景色 (亮色) |

## 三、颜色语义

| 颜色 | 色值 | 语义 |
|------|------|------|
| Indigo | `#4f46e5` | 主要操作、加载、创建 |
| Green | `#10b981` | 启动、保存、成功 |
| Red | `#ef4444` | 停止、删除、失败、错误 |
| Blue | `#3b82f6` | 编辑、信息、聚焦 |
| Gray | `#4b5563` / `#6b7280` | 通用、禁用、取消 |
