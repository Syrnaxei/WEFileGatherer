# 设置界面下拉框样式规范

> **版本**: 1.0
> **适用组件**: `web/src/components/SettingsPage.tsx` — `ProcessModeSelect`
> **关联样式**: `web/src/index.css` — `animate-fade-in-up` / `animate-fade-out-up`
> **最后更新**: 2026-05-15

---

## 一、概述

设置界面中的下拉选择框（如"文件处理模式"）采用完全自定义实现，替代浏览器原生 `<select>` 元素。展开时下拉面板覆盖（而非避开）触发按钮，视觉上与按钮融为一体。

## 二、组件结构

```
ProcessModeSelect
├── 外层容器 (position: relative)
│   ├── 触发按钮 <button>           ← 始终可见
│   └── 下拉面板 <div>              ← open=true 时渲染
│       ├── 选项行 × N              ← 每行含竖线标记 + 标签文字
│       │   ├── 选中竖线指示器       ← accent 色 3px 竖线
│       │   ├── 选项文字
│       │   └── chevron 箭头 (SVG)  ← 仅已选项显示
```

## 六、动画系统

### 6.1 展开动画

| 属性 | 值 |
|------|-----|
| CSS 类名 | `animate-fade-in-up` |
| 关键帧 | `fade-in-up`: `opacity 0→1` + `translateY(8px→0)` |
| 持续时间 | `250ms` |
| 缓动函数 | `cubic-bezier(0.16, 1, 0.3, 1)` (`var(--ease-out)`) |

定义于 [index.css](file:///e:/AAAProject/VideoFileProcessing/web/src/index.css#L377-L385)：

```css
@keyframes fade-in-up {
  from {
    opacity: 0;
    transform: translateY(8px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

### 6.2 收起动画

| 属性 | 值 |
|------|-----|
| CSS 类名 | `animate-fade-out-up` |
| 关键帧 | `fade-out-up`: `opacity 1→0` + `translateY(0→-6px)` |
| 持续时间 | `150ms` |
| 缓动函数 | `cubic-bezier(0.16, 1, 0.3, 1)` (`var(--ease-out)`) |

定义于 [index.css](file:///e:/AAAProject/VideoFileProcessing/web/src/index.css#L452-L462)：

```css
@keyframes fade-out-up {
  from {
    opacity: 1;
    transform: translateY(0);
  }
  to {
    opacity: 0;
    transform: translateY(-6px);
  }
}
```

### 6.3 收起时序

收起动画采用两阶段机制，确保动画播放完毕后再从 DOM 移除元素：

```
用户操作（点击选项 / 点击外部）
  → triggerClose()
    → setClosing(true)        ← 切换到 animate-fade-out-up 类
    → setTimeout(140ms)
      → setOpen(false)        ← 从 DOM 移除
      → setClosing(false)     ← 重置状态
```

### 6.4 chevron 箭头旋转

| 状态 | 变换 |
|------|------|
| 收起 | `rotate(0deg)` |
| 展开 | `rotate(180deg)` |
| 过渡 | `transform 200ms cubic-bezier(0.16, 1, 0.3, 1)` |

## 七、交互行为

### 7.1 展开

- 点击触发按钮 → `setOpen(true)` → 下拉面板渲染
- 面板从 `top: 0` 位置展开，覆盖按钮本身
- 已选项左侧显示 accent 竖线 + 右侧显示 chevron 箭头

### 7.2 收起

触发条件：
1. 点击某个选项 → 选择并收起
2. 点击面板外部区域 → 仅收起（不改变选中值）

收起时面板播放 `animate-fade-out-up`，140ms 后从 DOM 移除。

### 7.3 外部点击检测

```tsx
useEffect(() => {
  if (!open) return;
  const handler = (e: MouseEvent) => {
    if (containerRef.current && !containerRef.current.contains(e.target as Node)) {
      triggerClose();
    }
  };
  document.addEventListener('mousedown', handler);
  return () => document.removeEventListener('mousedown', handler);
}, [open]);
```

## 八、使用示例


```tsx
const processingModeOptions = [
```

## 九、与其他 UI 元素的关系

- 该自定义下拉框**仅用于设置界面**（SettingsPage）
- 设置界面其他输入控件（文本输入、ToggleSwitch、数值输入）均保持原生或简单实现
- 竖线指示器 + 覆盖式面板 + 淡入淡出动画的组合是设置界面独有的交互模式
