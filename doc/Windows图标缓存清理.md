# Windows 图标缓存清理方法

如果替换图标后，资源管理器中仍然显示旧图标，这是 Windows 图标缓存导致的，与程序本身无关。

## 方法一：重启资源管理器（推荐，最简单）

1. 打开任务管理器（Ctrl + Shift + Esc）
2. 找到 "Windows 资源管理器" 进程
3. 右键点击 → "重新启动"
4. 查看 `release/` 目录中的 exe 文件图标是否已更新

## 方法二：清理图标缓存文件

1. 关闭所有文件夹窗口
2. 打开命令提示符（管理员），依次执行：

```cmd
taskkill /f /im explorer.exe
cd /d %userprofile%\AppData\Local
del IconCache.db /a
shutdown /r /t 0
```

3. 系统会自动重启，重启后图标缓存即被重建

## 方法三：修改文件夹视图（不需要重启）

1. 打开 `release/` 文件夹
2. 右键空白处 → "查看"
3. 切换到 "详细信息"（或切换到其他视图）
4. 再切换回 "大图标" 或 "超大图标"
5. 有时这会强制刷新图标显示

## 验证图标是否已更新

可以通过以下方式确认新图标已正确打包：

1. **查看 ICO 文件**：用图片查看器打开 `build/icons/icon.ico`，确认内容已更新
2. **查看 EXE 属性**：右键 `release/win-unpacked/*.exe` → "属性" → "详细信息"，查看图标信息
3. **用 Resource Hacker**（可选）：打开 exe 文件查看内置的图标资源

## 预防措施

为避免每次都要清理缓存：

- 使用不同的文件名测试（如重命名 Setup 文件）
- 在不同的文件夹中测试
- 使用虚拟机或干净的 Windows 环境测试
