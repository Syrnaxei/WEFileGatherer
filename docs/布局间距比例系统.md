# 布局间距比例系统 (Layout Spacing Ratio System)

> 适用文件: `web/src/components/FileList.tsx`、`web/src/App.tsx`、`web/src/components/ScrapePage.tsx`

---

## 一、工作台文件列表 (FileList.tsx / App.tsx)

### 设计原则

所有列宽使用 `fr` 单位 + `minmax()` 约束，确保窗口缩放时各列按固定比例同步伸缩，避免固定像素列在窄屏下挤压弹性列的空间。

### 列宽比例

```
文件名 : Tag : 目标路径 : 操作 = 3 : 2 : 3 : 1
```

| 列 | 单位 | 用途 |
|----|------|------|
| 文件名 | `minmax(120px, 3fr)` | 主信息区，展示文件名+路径 |
| Tag | `minmax(140px, 2fr)` | 输入区，容纳下拉选择器+清除按钮 |
| 目标路径 | `minmax(120px, 3fr)` | 辅助信息区，展示 tag 对应的目标目录 |
| 操作 | `minmax(60px, 1fr)` | 按钮区，仅容纳删除图标 |

### 间距常量

| 常量 | 当前值 | 说明 | 建议范围 |
|------|--------|------|----------|
| `GRID_GAP` | `18px` | 列间距 | 8px ~ 20px |
| `ROW_PADDING` | `10px 12px` | 行内边距 (垂直 水平) | 垂直 8~14px, 水平 12~20px |
| `HEADER_PADDING` | `8px 16px` | 表头内边距 | 与 ROW_PADDING 保持视觉一致 |

### 调整方法

1. **修改列宽比例**: 修改 `GRID_COLUMNS` 中的 `fr` 数值
   - 例如改为 `'3fr 2fr 2fr 1fr'` 可压缩目标路径列
   - `fr` 总和无需等于固定值，浏览器会自动按比例分配

2. **修改最小宽度**: 修改 `minmax()` 第一个参数
   - 文件名建议范围: 100px ~ 150px
   - Tag 建议范围: 120px ~ 160px（需容纳输入框+清除按钮）
   - 路径建议范围: 100px ~ 150px
   - 操作建议范围: 50px ~ 80px

3. **修改列间距**: 修改 `GRID_GAP` 变量（建议范围: 8px ~ 20px）

4. **修改行内边距**: 修改 `ROW_PADDING` 变量

5. **修改表头内边距**: 修改 `HEADER_PADDING` 变量

> **注意**: App.tsx 中的表头网格使用相同的列宽和间距值，修改时需同步更新。

## 二、搜刮界面文件列表 (ScrapePage.tsx)

### 设计原则

使用 `table-layout: fixed` + 百分比列宽，确保窗口缩放时各列按固定比例同步伸缩。

### 列宽比例

```
文件名 : 路径 : 状态 : 操作 = 35 : 40 : 15 : 10
```

| 列 | 宽度 | 用途 |
|----|------|------|
| 文件名 | `35%` | 主信息区，展示视频文件名 |
| 路径 | `40%` | 辅助信息区，展示文件完整路径 |
| 状态 | `15%` (min 70px) | 状态标签区，展示处理状态徽章 |
| 操作 | `10%` (min 60px) | 按钮区，仅容纳删除按钮 |

### 间距常量

| 常量 | 当前值 | 说明 | 建议范围 |
|------|--------|------|----------|
| `CELL_PADDING` | `8px 12px` | 单元格内边距 | 垂直 6~12px, 水平 8~16px |
| `HEADER_PADDING` | `8px 12px` | 表头内边距 | 与 CELL_PADDING 保持一致 |
| `MIN_STATUS_WIDTH` | `70px` | 状态列最小宽度 | 60px ~ 100px |
| `MIN_ACTION_WIDTH` | `60px` | 操作列最小宽度 | 50px ~ 80px |

### 调整方法

1. **修改列宽比例**: 修改 `SCRAPE_COL_WIDTHS` 数组中的百分比值
   - 四个值之和应为 100
   - 例如改为 `[30, 45, 15, 10]` 可压缩文件名列、扩展路径列

2. **修改单元格内边距**: 修改 `CELL_PADDING` 变量

3. **修改表头内边距**: 修改 `HEADER_PADDING` 变量

4. **修改最小宽度**: 修改 `MIN_STATUS_WIDTH` / `MIN_ACTION_WIDTH` 变量

## 三、工作台缩略图视图 (FileList.tsx — ThumbnailView)

### 设计原则

缩略图视图比列表视图多一列"预览"，用于展示视频缩略图。预览列和操作列使用固定像素宽度，文件名和目标路径列使用 `fr` 弹性分配剩余空间。

### 列宽比例

```
预览(固定) + 文件名(1fr) + Tag(固定) + 目标路径(1fr) + 操作(固定)
```

| 列 | 宽度 | 单位 | 用途 |
|----|------|------|------|
| 预览 | `THUMB_COL_PREVIEW_SINGLE` (80px) 或 `THUMB_COL_PREVIEW_MULTI` (72px) | px | 视频缩略图预览 |
| 文件名 | `1fr` | fr | 弹性分配剩余空间 |
| Tag | `THUMB_COL_TAG` (160px) | px | Tag 下拉选择器 |
| 目标路径 | `1fr` | fr | 弹性分配剩余空间 |
| 操作 | `THUMB_COL_ACTION` (40px) | px | 删除按钮 |

### 间距常量

| 常量 | 当前值 | 说明 | 建议范围 |
|------|--------|------|----------|
| `THUMB_GRID_GAP` | `12px` | 列间距 | 8px ~ 20px |
| `THUMB_ROW_PADDING` | `10px 20px` | 行内边距 (垂直 水平) | 垂直 8~14px, 水平 12~20px |
| `THUMB_HEADER_PADDING` | `8px 20px` | 表头内边距 | 与行内边距保持视觉一致 |
| `THUMB_COL_PREVIEW_SINGLE` | `80px` | 单缩略图预览列宽 | 70px ~ 100px |
| `THUMB_COL_PREVIEW_MULTI` | `72px` | 多缩略图预览列宽 | 60px ~ 90px |
| `THUMB_THUMB_HEIGHT_SINGLE` | `45px` | 单缩略图高度 | 40px ~ 60px |
| `THUMB_THUMB_HEIGHT_MULTI` | `40px` | 多缩略图高度 | 35px ~ 50px |
| `THUMB_COL_TAG` | `160px` | Tag 列宽 | 140px ~ 180px |
| `THUMB_COL_ACTION` | `40px` | 操作列宽 | 36px ~ 50px |

### 调整方法

1. **修改预览列宽**: 修改 `THUMB_COL_PREVIEW_SINGLE` / `THUMB_COL_PREVIEW_MULTI`
2. **修改缩略图高度**: 修改 `THUMB_THUMB_HEIGHT_SINGLE` / `THUMB_THUMB_HEIGHT_MULTI`
3. **修改 Tag 列宽**: 修改 `THUMB_COL_TAG`（建议范围: 140px ~ 180px）
4. **修改操作列宽**: 修改 `THUMB_COL_ACTION`（建议范围: 36px ~ 50px）
5. **修改列间距**: 修改 `THUMB_GRID_GAP`
6. **修改行内边距**: 修改 `THUMB_ROW_PADDING`
7. **修改表头内边距**: 修改 `THUMB_HEADER_PADDING`

> **注意**: 预览列宽 `THUMB_COL_PREVIEW_SINGLE` / `THUMB_COL_PREVIEW_MULTI` 和缩略图高度 `THUMB_THUMB_HEIGHT_SINGLE` / `THUMB_THUMB_HEIGHT_MULTI` 的值同时影响 `gridCols` 模板中的列宽和缩略图容器的宽高样式。修改时需保持两组常量的一致性。
