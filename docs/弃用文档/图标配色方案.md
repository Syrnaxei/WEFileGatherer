# 图标配色方案（夜间/非夜间模式）

> 适用文件: `web/src/components/Sidebar.tsx`、`web/src/components/FileList.tsx`、`web/src/components/TagManagement.tsx`、`web/public/*.svg`

---

## 一、设计原则

- 所有 SVG 图标使用 `fill="currentColor"`，颜色由父元素的 `color` CSS 属性控制
- 图标颜色随主题（夜间/非夜间）自动切换，无需额外逻辑
- 交互状态（默认、悬停、激活、禁用）各有独立的颜色定义

## 七、SVG 图标文件规范

所有 `web/public/*.svg` 文件必须满足：

1. `fill` 属性设置为 `"currentColor"`（而非硬编码色值）
2. 如需多色图标，可使用 CSS 变量或单独的 CSS 类控制

## 八、新增图标指南

1. 将 SVG 文件放入 `web/public/` 目录
2. 确保 `fill="currentColor"`（或需要主题化的路径使用 `currentColor`）
3. 在组件中通过 `color` 属性控制图标颜色
4. 参考 `Sidebar.tsx` 中的图标组件模式：使用 `React.FC<{ size?: number }>` 类型，通过 `fill="currentColor"` 继承父元素颜色
