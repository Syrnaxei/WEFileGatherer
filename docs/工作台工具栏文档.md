# 工作台工具栏文档

## 概述

`WorkspaceToolbar` 是工作台页面的横置工具栏组件，位于 `PageHeader` 与文件列表之间，采用工厂注册模式维护工具项。工具栏样式参考横置的侧边栏，但无展开/折叠功能，整体紧凑。

- **组件路径**：`web/src/components/winui/WorkspaceToolbar.tsx`
- **导出**：`WorkspaceToolbar`（组件）、`toolbarFactory`（工厂实例）、`ToolbarItemConfig`（类型）

---

## 架构

```
┌─────────────────────────────────────────────┐
│              ToolbarFactory                  │
│  ┌───────────┐  ┌────────────────┐          │
│  │ register() │  │  unregister()  │          │
│  └───────────┘  └────────────────┘          │
│  ┌───────────┐  ┌────────────────┐          │
│  │  getAll()  │  │    get(id)     │          │
│  └───────────┘  └────────────────┘          │
│                                             │
│  registry: Map<string, ToolbarItemConfig>   │
└──────────────────┬──────────────────────────┘
                   │ getAll()
                   ▼
┌─────────────────────────────────────────────┐
│           WorkspaceToolbar                   │
│  遍历工厂配置 → 绑定运行时状态 → 渲染按钮    │
└─────────────────────────────────────────────┘
```

工具项的**静态配置**（id、icon、label）通过工厂注册，**运行时状态**（disabled、active、onClick）由组件内部根据 props 动态绑定。两者解耦，便于扩展。

## 注册工具

### 接口定义

```typescript
/** 工具栏项注册配置（不含运行时状态） */
interface ToolbarItemConfig {
  /** 唯一标识，用于匹配运行时状态 */
  id: string;
  /** 图标组件，接收 size 参数 */
  icon: React.FC<{ size?: number }>;
  /** 标签文字，显示为按钮 title */
  label: string;
}
```

### 注册方法

```typescript
import { toolbarFactory } from '@/components/winui';

// 注册新工具项
toolbarFactory.register({
  id: 'my-tool',
  icon: MyToolIcon,
  label: '我的工具',
});
```

### 注销方法

```typescript
// 注销工具项
toolbarFactory.unregister('my-tool');
```

### 查询方法

```typescript
// 获取所有已注册配置
const allItems = toolbarFactory.getAll();

// 获取指定配置
const config = toolbarFactory.get('my-tool');
```

## 添加新工具的完整步骤

以添加「刷新」工具为例：

### 1. 定义图标组件

图标使用 `fill="currentColor"` 以适配深色/浅色主题。SVG 路径可从 `web/public/fluenticons/` 目录下的图标文件中提取。

```tsx
function RefreshIcon({ size = 16 }: { size?: number }) {
  return (
    <svg width={size} height={size} fill="none" viewBox="0 0 24 24">
      <path d="M..." fill="currentColor" />
    </svg>
  );
}
```

### 2. 注册到工厂

在 `WorkspaceToolbar.tsx` 底部的注册区域添加：

```tsx
toolbarFactory.register({
  id: 'refresh',
  icon: RefreshIcon,
  label: '刷新',
});
```

### 3. 绑定运行时状态

在 `WorkspaceToolbar` 组件内部的 `switch (config.id)` 中添加 case：

```tsx
case 'refresh':
  disabled = !!isRunning;
  onClick = onRefresh;  // 需在 WorkspaceToolbarProps 中新增此回调
  break;
```

### 4. 传递回调

在 `WorkspaceToolbarProps` 中新增回调 prop，并在 `WorkspacePage.tsx` 中传入：

```tsx
// WorkspaceToolbarProps
interface WorkspaceToolbarProps {
  // ...已有 props
  onRefresh: () => void;
}

// WorkspacePage.tsx
<WorkspaceToolbar
  // ...已有 props
  onRefresh={handleRefresh}
/>
```

## 样式参数

工具栏采用紧凑尺寸，参数如下：

| 参数         | 值   | 说明               |
| ------------ | ---- | ------------------ |
| buttonSize   | 32px | 按钮宽高           |
| iconSize     | 16px | 图标大小           |
| marginX      | 2px  | 按钮水平间距       |
| marginY      | 6px  | 上下内边距         |
| padding      | 10px | 工具栏左右内边距   |
| borderRadius | 4px  | 按钮圆角           |

按钮交互样式：

- **默认**：透明背景，`var(--text-muted)` 颜色
- **Hover**：`var(--bg-surface-3)` 背景，`var(--text-secondary)` 颜色
- **Active**：`var(--bg-surface-3)` 背景，`var(--text-primary)` 颜色
- **Disabled**：透明背景，`var(--text-disabled)` 颜色，0.4 透明度
- **过渡**：`150ms ease`

## 图标资源

Fluent UI 图标 SVG 文件位于 `web/public/fluenticons/` 目录。使用步骤：

1. 打开目标 SVG 文件，提取 `<path>` 的 `d` 属性值
2. 创建图标组件，将 `fill` 改为 `currentColor`
3. 设置 `viewBox="0 0 24 24"` 保持统一

示例（从 `Delete.svg` 提取）：

```tsx
function DeleteSelectedIcon({ size = 16 }: { size?: number }) {
  return (
    <svg width={size} height={size} fill="none" viewBox="0 0 24 24">
      <path d="M12 1.75a3.25..." fill="currentColor" />
    </svg>
  );
}
```
