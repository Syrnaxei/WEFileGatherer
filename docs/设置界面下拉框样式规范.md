# 设置界面下拉框样式规范

## 概述

设置界面"高级设置"中的"文件处理模式"下拉框采用完全自定义的 React 组件 `ProcessModeSelect`，替代原生 `<select>` 元素，实现 Windows UWP 风格的交互动画。

组件位置：[SettingsPage.tsx](../web/src/components/SettingsPage.tsx) — `ProcessModeSelect` 函数组件。

---

## 1. 组件结构

```
<div ref={containerRef} style={{ position: 'relative' }}>   ← 定位容器
  <button>                                                    ← 触发按钮（始终可见）
    <span>{selectedLabel}</span>
    <svg>chevron</svg>                                        ← 展开/收起箭头
  </button>

  {open && (                                                  ← 条件渲染下拉面板
    <div className="animate-fade-in-up / animate-fade-out-up"> ← 动画层（定位 + 动画）
      <div style={{ transform: scale(1.02) }}>                ← 缩放层（视觉样式）
        <div>选项 1</div>                                      ← 选项行
        <div>选项 2</div>
      </div>
    </div>
  )}
</div>
```

### 分层职责

| 层级 | 元素 | 职责 |
|------|------|------|
| 容器 | `containerRef` div | `position: relative` 定位锚点，点击外部检测 |
| 触发按钮 | `<button>` | 显示当前选中值 + chevron 箭头，点击展开/收起 |
| 动画层 | 外层 div | `position: absolute` + 动画 className，控制出现/消失 |
| 缩放层 | 内层 div | `transform: scale(1.02)` 容器放大，承载背景/边框/阴影 |
| 选项行 | 内层 div × N | 每个选项的交互区域 |

## 4. 下拉面板样式

### 4.1 动画层（外层 div）

| 属性 | 值 | 说明 |
|------|-----|------|
| `position` | `absolute` | 绝对定位 |
| `top` | `offsetY`（动态计算） | 使已选项对齐触发按钮位置 |
| `left` / `right` | `0` | 与触发按钮等宽 |
| `z-index` | `100` | 层级 |

**offsetY 计算**：
```typescript
const selectedIndex = processingModeOptions.findIndex((o) => o.value === value);
const optionHeight = 32; // 单选项高度：6px padding-top + 20px line-height + 6px padding-bottom
const offsetY = -selectedIndex * optionHeight;
```

| 已选项 | selectedIndex | offsetY | 效果 |
|--------|:------------:|:-------:|------|
| 并行模式（第 1 项） | 0 | `0` | 面板不偏移 |
| FIFO 模式（第 2 项） | 1 | `-32px` | 面板上移 32px |

### 4.2 缩放层（内层 div）

| 属性 | 值 | 说明 |
|------|-----|------|
| `background` | `var(--bg-surface-2)` | 背景色 |
| `border` | `1px solid var(--border-default)` | 边框 |
| `border-radius` | `var(--radius-sm)` (6px) | 圆角 |
| `overflow` | `hidden` | 裁剪溢出（圆角生效） |
| `box-shadow` | `var(--shadow-md)` | 阴影 |
| `transform` | `scale(1.02)` | 容器放大 2% |
| `transform-origin` | `top left` | 从左上角缩放 |

> **注意**：`scale(1.04)` 仅作用于容器尺寸，选项内的 `font-size` 保持 `13px` 不变。缩放层与动画层分离，避免 `transform` 属性冲突。

## 6. 动画规范

### 6.1 展开动画

CSS 类：`animate-fade-in-up`

```css
@keyframes fade-in-up {
  from {
    opacity: 0;
    transform: translateY(8px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.animate-fade-in-up {
  animation: fade-in-up var(--duration-normal) var(--ease-out);
}
```

- 持续时间：`var(--duration-normal)` (250ms)
- 缓动函数：`var(--ease-out)` (`cubic-bezier(0, 0, 0.2, 1)`)
- 效果：淡入 + 向下位移 8px → 0

### 6.2 收起动画

CSS 类：`animate-fade-out-up`

```css
@keyframes fade-out-up {
  from {
    opacity: 1;
    transform: translateY(0);
  }
  to {
    opacity: 0;
    transform: translateY(-6px);
  }
}

.animate-fade-out-up {
  animation: fade-out-up 150ms var(--ease-out) forwards;
}
```

- 持续时间：150ms
- `forwards`：保持动画结束状态
- 效果：淡出 + 向上位移 0 → -6px

### 6.3 收起时序

```
用户点击选项（或点击外部）
  → setClosing(true)           // 触发淡出动画
  → setTimeout 140ms
    → setOpen(false)            // 移除 DOM
    → setClosing(false)         // 重置状态
```

动画时长 150ms，setTimeout 140ms 略早于动画结束，利用 `forwards` 保持最后帧避免闪烁。

## 7. 交互状态机

```
         click 按钮
  收起态 ──────────→ 展开态
    ↑                  │
    │    click 选项    │
    │    click 外部    │
    │    click 按钮    │
    └──────────────────┘
```

| 状态 | open | closing | 视觉效果 |
|------|:----:|:-------:|----------|
| 收起 | `false` | `false` | 仅显示触发按钮 |
| 展开 | `true` | `false` | 下拉面板 `animate-fade-in-up` |
| 收起中 | `true` | `true` | 下拉面板 `animate-fade-out-up` |

## 8. 点击外部关闭

```typescript
useEffect(() => {
  if (!open) return;
  const handler = (e: MouseEvent) => {
    if (containerRef.current && !containerRef.current.contains(e.target as Node)) {
      triggerClose();
    }
  };
  document.addEventListener('mousedown', handler);
  return () => document.removeEventListener('mousedown', handler);
}, [open]);
```

- 监听 `document` 的 `mousedown` 事件
- 判断点击目标是否在 `containerRef` 之外
- 组件卸载或 `open` 变化时自动清理监听
