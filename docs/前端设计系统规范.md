## 一、概述

本设计系统是 SVFP 前端的唯一样式标准。**核心原则：所有颜色、间距、圆角、阴影均通过 CSS 自定义属性 (`var(--xxx)`) 引用，禁止在组件中硬编码色值。**

```css
/* ✓ 正确：使用 CSS 变量 */
background: var(--bg-surface-1);
color: var(--text-primary);

/* ✗ 错误：硬编码色值 */
background: #1f2937;
color: #e5e7eb;
```

架构要点：
- CSS 变量定义在 `index.css` 的 `:root` / `[data-theme="dark"]` / `[data-theme="light"]` 中
- 暗色主题为默认（`data-theme="dark"`），亮色通过 `data-theme="light"` 切换
- `ThemeContext` 负责读取/持久化主题偏好，并同步 `document.documentElement` 的 `data-theme` 属性
- 字体文件通过 `@fontsource` npm 包本地引入（`main.tsx`），无外部 CDN 依赖
- 组件**不应**通过 `isDark` prop 做颜色判断——CSS 变量自动处理主题切换。`isDark` 仅用于非颜色行为差异

## 三、字体系统

### 3.1 字体引入

字体通过 `@fontsource` 包本地引入，定义于 `main.tsx`：

```ts
import '@fontsource/dm-sans/latin-400.css'
import '@fontsource/dm-sans/latin-500.css'
import '@fontsource/dm-sans/latin-600.css'
import '@fontsource/dm-sans/latin-700.css'
import '@fontsource/jetbrains-mono/latin-400.css'
import '@fontsource/jetbrains-mono/latin-500.css'
import '@fontsource/jetbrains-mono/latin-600.css'
```

Vite 构建时自动将 `.woff2`/`.woff` 文件输出到 `dist/assets/`，无需任何外部网络请求。

### 3.2 字体变量

| CSS 变量 | 字体栈 | 用途 |
|----------|--------|------|
| `--font-ui` | `'DM Sans', system-ui, -apple-system, sans-serif` | 界面文字、按钮、标签 |
| `--font-mono` | `'JetBrains Mono', 'Cascadia Code', 'Fira Code', monospace` | 文件路径、日志、代码 |

> **注意**: 中文字符在 DM Sans 和 JetBrains Mono 中无对应字形，会自动回退到 `system-ui` / `sans-serif` 渲染。

### 3.3 字号层级

| 场景 | 字号 | 字重 | 字体系列 |
|------|------|------|---------|
| 页面标题 | `18px` | `700` | `--font-ui` |
| 设置项标题 | `16px` | `500` | `--font-ui` |
| 区块标题 | `14px` | `600` | `--font-ui` |
| 正文/按钮/子项标签 | `13px` | `400~500` | `--font-ui` |
| 辅助说明/路径 | `12px` | `400~500` | `--font-ui` / `--font-mono` |
| 小标签/表头 | `11px` | `500~600` | `--font-ui` |
| 状态徽章 | `10px` | `600` | `--font-ui` |
| 统计数字 | `26px` | `700` | `--font-mono` |
| 路径/日志/代码 | `11~12px` | `400~500` | `--font-mono` |

### 3.4 letter-spacing 规范

| 场景 | 值 |
|------|-----|
| 标题/正文 | `-0.01em ~ -0.02em`（紧凑） |
| 大写表头 | `0.04em`（松散） |
| 状态徽章 | `0.02em` |

## 四、间距系统

基于 **4px 网格**，所有间距均为 4 的倍数：

| CSS 变量 | 值 | 典型用途 |
|----------|-----|---------|
| `--space-1` | `4px` | 极小间距 |
| `--space-2` | `8px` | 按钮间距、图标间距 |
| `--space-3` | `12px` | 卡片间距、内边距 |
| `--space-4` | `16px` | 标准间距、gap |
| `--space-5` | `20px` | 页面水平内边距 |
| `--space-6` | `24px` | 区块间距 |
| `--space-8` | `32px` | 大区块间距 |

**页面水平内边距**: 统一使用 `20px`
**设置页面内容区内边距**: `24px`
**设置区块垂直间距**: `24px`
**卡片/区块垂直间距**: `16px`
**按钮间距**: `8px`
**统计卡片间距**: `12px`

### 布局列宽比例

沿用已有规范，详见 [布局间距比例系统.md](./布局间距比例系统.md)：
- 列表视图文件列表: `文件名 : Tag : 目标路径 : 进度 : 操作 = 3 : 2 : 3 : 1 : 1`（近似）
- 缩略图视图文件列表: `预览 : 文件名 : Tag : 目标路径 : 进度 : 操作`

## 六、CSS 工具类

定义于 `index.css`，可直接通过 `className` 使用：

### 6.1 按钮 `.btn`

```html
<button className="btn btn-primary">主要操作</button>
<button className="btn btn-success">启动</button>
<button className="btn btn-danger">停止/删除</button>
<button className="btn btn-ghost">取消</button>
<button className="btn btn-outline">编辑</button>
```

| 类名 | 样式 | 用途 |
|------|------|------|
| `.btn` | 基础样式（padding/font/transition） | 所有按钮必加 |
| `.btn-primary` | `bg: --accent`, `color: --md-sys-color-on-primary` | 加载、创建等主要操作 |
| `.btn-success` | `bg: --success`, `color: white` | 启动、保存 |
| `.btn-danger` | `bg: --error`, `color: white` | 停止、删除 |
| `.btn-ghost` | 透明底 + `color: --text-secondary` | 取消、丢弃 |
| `.btn-outline` | 透明底 + `border: 1px solid --border-default` | 编辑、选择目录 |

`.btn` 基础样式包含：
- `display: inline-flex; align-items: center; justify-content: center; gap: 8px`
- `padding: 6px 16px`、`font-size: 13px`、`font-weight: 500`
- `border-radius: var(--radius-sm)`、`border: none`
- `transition: all 150ms cubic-bezier(0.16, 1, 0.3, 1)`
- `font-family: var(--font-ui)`、`letter-spacing: -0.01em`
- `:active` 时 `scale(0.97)` 微缩反馈
- `:disabled` 时 `opacity: 0.45` + `cursor: not-allowed` + `pointer-events: none`

### 6.2 文件夹选择按钮 `.btn-folder-select`

```html
<button className="btn-folder-select">选择...</button>
```

独立于通用 `.btn` 体系，无边框填充色背景：
- `background: var(--btn-folder-bg)`、`border: none`

- `border-radius: var(--radius-sm)`
- 悬停时 `background: var(--btn-folder-hover-bg)`

### 6.3 输入框 `.input`

```html

<input className="input input-mono" placeholder="路径或代码..." />
```

`.input` 基础样式包含：
- 全宽、`padding: 7px 10px`、`font-size: 13px`
- `background: var(--bg-surface-2)`、`border: 1px solid var(--border-default)`
- `:focus` 时边框变 `--accent` + `box-shadow: 0 0 0 3px var(--accent-muted)`
- `:disabled` 时 `opacity: 0.45`
- `::placeholder` 颜色为 `--text-muted`
- `user-select: text`（允许选择输入框内文字）

`.input-mono` 修饰符：使用 `--font-mono` 字体，`font-size: 12px`

## 九、动画系统

### 9.1 缓动函数

| CSS 变量 | 值 | 用途 |
|----------|-----|------|

|----------|-----|------|

| `--duration-slow` | `400ms` | 大幅动画（预留） |

### 9.3 关键帧动画

| 名称 | 效果 | 使用位置 |
|------|------|---------|
| `fade-in` | 透明度 0→1 | 通用淡入 |

| `fade-in-down` | 透明度 0→1 + Y轴 -8px→0 | （预留） |
| `fade-out` | 透明度 1→0 | 通用淡出 |
| `fade-out-up` | 透明度 1→0 + Y轴 0→-6px | 下拉面板关闭 |
| `slide-in-right` | 透明度 0→1 + X轴 24px→0 | Toast 进入 |
| `slide-in-left` | 透明度 0→1 + X轴 -16px→0 | （预留） |
| `scale-in` | 透明度 0→1 + 缩放 0.95→1 | （预留） |
| `pulse-glow` | 外发光脉冲 | （预留） |
| `status-pulse` | 透明度 1→0.5→1 | 连接状态指示点 |
| `shimmer` | 骨架屏扫光 | `.skeleton` 加载占位 |

### 9.4 微交互规范

- **按钮点击**: `:active { transform: scale(0.97) }`

## 十、主题切换

### 10.1 架构

```
ThemeContext (React State: 'light' | 'dark' | 'system')
    ↓ setMode()
document.documentElement.setAttribute('data-theme', 'dark'|'light')
    ↓ CSS 变量自动切换
所有使用 var(--xxx) 的元素自动响应
```

### 10.2 核心代码

`ThemeContext.tsx`:
```tsx
function applyTheme(theme: ThemeMode) {
  document.documentElement.setAttribute('data-theme', theme);
}
```

`index.css`:
```css
:root, [data-theme="dark"] { /* 暗色变量 */ }
[data-theme="light"] { /* 亮色变量覆盖 */ }
```

### 10.3 组件中获取主题

```tsx
import { useTheme } from '../contexts/ThemeContext';

const { isDark, mode, setMode } = useTheme();
// isDark: boolean — 当前是否为暗色模式
// mode: 'light' | 'dark' | 'system'
// setMode: 切换并持久化
```

> **注意**: 新组件应优先使用 CSS 变量处理颜色，仅在有非颜色逻辑差异时才使用 `isDark`。如果组件接收了 `isDark` prop 但只用于颜色判断，应去掉并以 `_isDark` 前缀标记未使用。

## 十一、新增界面指南

### 11.1 新建组件清单

添加新 UI 组件时，按以下顺序操作：

1. **颜色**: 全部使用 `var(--xxx)` 引用，不硬编码。若有新语义色需求，先添加到 `index.css` 的 `:root` 两个主题区
2. **WinUI 组件**: 检查 `web/src/components/winui/` 是否有可复用的现成组件（设置项行块、展开块、Toggle 等）
3. **字体**: 界面文字用 `var(--font-ui)`，路径/代码用 `var(--font-mono)`
4. **间距**: 使用 4px 网格（`--space-1` ~ `--space-8`），页面水平内边距统一 `20px`
5. **圆角**: 按钮/输入框用 `--radius-sm`，卡片用 `--radius-md`，大容器用 `--radius-lg`
6. **按钮**: 优先使用 `.btn` 工具类（`className="btn btn-primary"` 而非手写 style）
7. **输入框**: 优先使用 `.input` 工具类
8. **设置页**: 使用 `--settings-page-bg` 背景 + WinUI 组件（`SettingsSection`、`SettingsTile`、`ExpandableTile` 等）
9. **空状态**: 遵循 8.8 空状态模式
10. **动画**: 进入动画用 `.animate-fade-in-up`，微交互用 150ms ease 过渡
11. **响应式**: 使用 flex/grid + minmax 确保内容自适应
12. **主题**: 不需要 `isDark` prop 来切换颜色（CSS 变量自动处理），仅在有行为差异时使用

### 11.2 检查清单

- [ ] 没有硬编码颜色值（`#xxx`）

- [ ] 设置页使用了 WinUI 组件而非手写样式结构
- [ ] 代码/路径文字使用了 `--font-mono`
- [ ] 间距是 4 的倍数
- [ ] 暗色和亮色主题均已测试
